  ---------- --------------------------------------------------------

# 5. How to Update

### 1. Start Work

When you begin a task:

``` text
To Do → In Progress
```

Do this only for the task you are actively working on.

### 2. Finish Work

Only mark a task:

``` text
In Progress → Done
```

when it works, the relevant test has passed, and the change has been
committed to Git.

### 3. Get Blocked

When something prevents progress:

``` text
In Progress → Blocked
```

Then write the exact reason in `Notes/Blockers`.

Example:

``` text
Blocked — waiting for Hostinger database credentials.
```

### 4. Keep One Source of Truth

Update `TRACKER.md` at the end of every work session. Do not rely on
memory to reconstruct what was completed.

Table/constraint created

+ Committed
